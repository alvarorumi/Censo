# Census Data Analysis - Excel

## Description

This project consists of analyzing a census dataset using Microsoft Excel. The main objective is to work with the data using formulas, PivotTables, charts, conditional formatting, slicers, timelines, and dashboards.

The project covers data processing, salary and demographic analysis, dynamic tables, and data visualization.

## Project Contents

The main file included in this repository is:

* `Censo_base.xlsx` — Excel workbook containing the completed exercises and analysis.

## Data Analysis

The main `Censo` worksheet includes different calculations and data transformations, such as:

* Formatting the data table.
* Calculating the total number of family members.
* Finding the maximum and minimum salary.
* Calculating the average salary and rounding it to one decimal place.
* Creating a full name in the format `Last Name, First Name`.
* Calculating initials.
* Calculating the number of letters in each person's first and last name.
* Calculating each person's age.
* Finding the day of the week on which each person was born.
* Extracting the year, month, and day from the date of birth.
* Identifying whether a person's profession is Engineer.
* Checking whether a family meets the specified salary and family-size condition.
* Creating a country order using a separate `País` worksheet.
* Applying conditional formatting to the salary column.

## PivotTables

The workbook contains several PivotTables used to analyze the dataset, including:

* Sum, average, minimum, and maximum salary by profession.
* Number of people born in each year.
* Number of people born in each month.
* Average salary by nationality and profession.
* Average salary by nationality and profession for families with more than three members.
* Percentage of total salary by profession.
* Percentage of total salary by profession and nationality.
* Salary analysis using nationality filters and a birth-year Timeline.
* Salary per capita by nationality.
* Different PivotTable layouts and configurations.

## Data Visualization

The project also includes several charts and visualizations:

* Salary histogram.
* Salary Pareto chart.
* Scatter plot showing the relationship between debt and salary.
* Bar chart showing the number of people by profession.
* Pie chart comparing salary and debt.
* Dynamic chart showing the evolution of average salary by birth year.
* Comparison of average, minimum, and maximum salary by birth year.
* Comparison of average salary and average family size using two axes.
* A dashboard containing the generated charts and filters.
